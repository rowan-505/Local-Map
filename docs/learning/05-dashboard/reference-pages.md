# Reference pages

CRUD for lookup tables under `/dashboard/references/`.

## Examples

POI categories, road classes, building types, admin levels, languages, report types, publish statuses, validation statuses.

## API

`/admin/ref/*` module in API.

## Purpose

Controlled vocabulary instead of database enums. Changes affect forms, validation, and display across core-review and import-review.
